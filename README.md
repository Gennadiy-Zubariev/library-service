# library-service

Online management system for book borrowings — REST API built with Django REST Framework.

Practice project implementing a real-world backend service with authentication,
payments (Stripe), notifications (Telegram), and scheduled tasks (Celery).

## Tech Stack

- Python 3.11+ / Django 5.x / Django REST Framework
- PostgreSQL, Redis
- Celery, Celery Beat
- Stripe API, Telegram Bot API
- JWT authentication (simplejwt)
- Docker, docker-compose
